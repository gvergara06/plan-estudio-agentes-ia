# Plan de Estudio — Agentes de IA

Ruta de aprendizaje para construir **agentes de IA de nivel empresarial y monetizables** en AWS
(Strands Agents + Amazon Bedrock + AgentCore).

## Contenido

- **[`plan-estudio-agentes-ia.md`](./plan-estudio-agentes-ia.md)** — fuente de verdad: 8 fases (Prerrequisitos → 0-7) + capstone, recursos, cronograma de ~14 semanas y mini-entregables por fase.
- **[`index.html`](./index.html)** — tracker interactivo del plan. Abrilo con doble clic (funciona offline, sin build).
- **[`CLAUDE.md`](./CLAUDE.md)** — instrucciones de proyecto para Claude Code (stack, convenciones, cómo asistir).

## Tracker (`index.html`)

Página autónoma para seguir el curso y guardar tu avance:

- Checkbox por lectura, curso, tema y entregable de cada fase (progreso por fase en vivo).
- Cronograma de 14 semanas marcable, con hitos.
- Notas por fase.
- Anillo de progreso global + contadores (tareas, entregables, semanas).
- **Guardado automático** en el navegador (`localStorage`).
- **Exportar / Importar** el avance como JSON — para respaldo o para llevarlo entre dispositivos.

> El avance vive en el navegador donde abrís la página, no en el repo. Usá *Exportar* para respaldarlo.

## Stack

Python (async) · Amazon Bedrock (Converse API) · Strands Agents · MCP · Bedrock Knowledge Bases · AgentCore · Pydantic.
